# Contributing

Thank you for contributing to the wef_oceans repository. To keep this project maintainable:

- Use a modern Python runtime (3.11 or 3.12).
- Install project dependencies with Poetry:
  - `poetry install`
  - `poetry install --extras geo` for geospatial workflows
- Run tests before submitting changes: `poetry run pytest`.

## Reporting issues

- Open a GitHub issue for bugs, missing documentation, or feature requests.
- Include reproduction steps, expected behavior, and relevant error output.

## Code style

- Keep new Python code simple and readable.
- Avoid committing credentials or secret files.
